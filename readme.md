# NymPlayer

A small Windows app that plays live audio from an input device, such as a USB audio interface or line-in, through any output device, such as speakers or Bluetooth headphones.

## Features

- **Pick input and output** from the Windows device lists, or choose "Windows default" to follow the system default device.
- **Play / Stop** to start or stop the audio passthrough.
- **Level meters** for input and output.
- **Remembers your devices.** The chosen devices are saved and selected again on the next start.
- **Automatic device switching.** If the chosen device is unplugged, playback moves to the Windows default and switches back when the device returns. "Windows default" follows changes to the system default.
- **Sample-rate conversion.** Input and output can run at different sample rates, and mono input is played on both channels.

## Build and run

Requires Windows and the [Rust toolchain](https://rustup.rs) (MSVC).

```sh
cargo build --release
target/release/nymplayer.exe
```

Run the tests with `cargo test`.

## Notes

- Settings are stored in `%APPDATA%\NymPlayer\settings.txt`.
- Latency through the app is about 15–60 ms. Bluetooth headphones add their own delay, typically 150–250 ms.
- Devices are remembered by name, so two identical USB devices can't be told apart.
- The icon is generated by `assets/make_icon.py` (Python standard library only).

Built with [cpal](https://github.com/RustAudio/cpal) for audio, [egui/eframe](https://github.com/emilk/egui) for the GUI, and [ringbuf](https://github.com/agerasev/ringbuf).
